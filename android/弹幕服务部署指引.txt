FnPlayer 安卓端 · 完整弹幕服务部署指引（免费云部署 · 可选）
================================================

【现在的默认情况：应用已内置完整弹幕核心】
从 1.2.0 起，APK 内置了完整的弹幕核心（Node 运行时 + danmu_api 核心），
应用启动时会在本机 127.0.0.1:9322 静默拉起，聚合豆瓣 / 360 / 人人 / 韩剧TV /
腾讯 / 优酷 / 爱奇艺 / 咪咕 / B站 / 弹弹play 等平台，国产剧与电影也能匹配到
弹幕。实测：庆余年 4 条、繁花 16 条、流浪地球 7 条（旧的内置镜像全是 0 条）。

所以一般不需要做本指引里的事。只有下面这些情况才需要自建云端实例：
  - 你所在的网络访问不了部分平台（例如腾讯/优酷源取不回弹幕正文）；
  - 想用自己部署的 danmu_api，或想用别人提供的高质量实例；
  - 想在多台设备间共用同一套弹幕服务。

【为什么仍然可以自建】
APK 内置核心与完整 danmu_api 服务的能力一致，但自建实例可以：
  - 绑定你自己的 Cookie（豆瓣/B站），提升搜索与弹幕成功率；
  - 在核心起不来时作为备用（设置里填地址即可自动接管）；
  - 给局域网里的其它设备（电视盒子等）共用。

【部署方式（任选其一，均有免费额度）】
上游项目：https://github.com/huangxd-/danmu_api
README 的「部署到 Vercel / Netlify / 腾讯云 EdgeOne Makers / Cloudflare /
Hugging Face Spaces / Docker」章节都提供一键部署入口。国内手机建议优先：
    1) 腾讯云 EdgeOne Makers（国内访问较快，README 内有一键部署按钮）
    2) Vercel / Netlify（免费额度足够个人使用）
    3) Cloudflare Workers / Pages
    4) 自己有服务器：Docker 一行命令启动

以「一键部署」为例：
  1. 打开上游 README 的部署章节，点对应平台的一键部署按钮，用你自己的
     GitHub / 云平台账号导入（fork 到你自己账号下）。
  2. 在环境变量里设置 TOKEN（自定义 8~16 位字符，记下来）。
     不设置时为默认值 87654321，此情况下也可以省略路径中的 TOKEN。
  3. 部署完成后得到公网域名，例如：
       https://danmu-api-xxxx.edgeone.app
       https://danmu-api-xxxx.vercel.app
  4. 在浏览器里验证（把域名和 TOKEN 换成你自己的）：
       https://<域名>/<TOKEN>/api/v2/search/anime?keyword=庆余年
     应返回 JSON，且 "animes" 数组里能看到「庆余年」相关条目。
     再测自动匹配接口（POST）：
       https://<域名>/<TOKEN>/api/v2/match
       body: {"fileName":"庆余年 S01E01"}
     应返回 "isMatched": true 和 episodeId。
  5. 手机打开 FnPlayer -> 设置 -> 弹幕 -> 「自定义弹幕服务」填：
       https://<域名>/<TOKEN>
     注意：不要带 /api/v2（应用会自动补），不要填 127.0.0.1（那是手机自己，
     会被自动忽略）。点「测试地址」应提示「测试通过 · HTTP 200 · 返回 N 条」，
     然后点「保存弹幕设置」。
  6. 回到播放页点「重新匹配」。配置完整服务后，自动匹配会优先调用
     POST /api/v2/match，一次请求完成跨平台匹配与集数定位；未命中时才会
     回退到本地多关键词搜索。

【常见问题】
- 提示「弹幕服务不可达 / HTTP 4xx」：检查地址是否多写了 /api/v2、TOKEN 是否
  正确、域名能否访问；用设置页「测试地址」看具体错误。
- 提示 429：请求过于频繁被限流，等几十秒再试，不要连续快速切集。
- 提示「已匹配到剧集，但返回 0 条弹幕」：该集弹幕上游暂未取到，点
  「重新匹配」重试；换线路或换集也可能有差异。
- 设置页仍显示「内置镜像（仅弹弹play 番剧库）」：说明地址没保存成功，或填了
  127.0.0.1 被忽略。保存后点「重新检测」。
- 「未找到匹配弹幕」后面会跟着具体原因（上游没有该片名 / 相似度不足 /
  已尝试 N 个片名变体）以及上游耗时，便于排查。
- 手机用移动数据时也能用：云端是公网地址，与家里电脑是否开机无关。

【片名清洗】
苹果CMS 片名常带「更新至152集」「(2024)」「HD」「【4K】」「第二季」
「S01E03」等后缀，直接拿去搜索会返回 0 条。新版会自动生成多个片名变体
依次尝试，并对搜索结果做相似度校验，避免把「狂飙」误匹配成「弹速狂飙」。
